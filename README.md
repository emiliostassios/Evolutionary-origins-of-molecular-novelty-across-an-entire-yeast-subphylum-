# Evolutionary Dynamics of De Novo Genes in Budding Yeasts

This repository contains the data and R scripts used to analyze the emergence, divergence, and properties of *de novo* genes across 332 species of *Saccharomycotina*. The analysis covers proteomic similarities, horizontal gene transfer (HGT), sequence divergence, and regulatory motif distributions.

## Repository Structure

```text
├── data/
│   ├── matrices/                 # Main data matrices (e.g., gene properties, motifs)
│   ├── trees/                    # Phylogenetic trees
│   ├── gene_lists                # List of gene codes per category
│   └── assemblies/               # Motif coverage and genome size summaries
├── scripts/
│   └── figure_generation.R       # Main R script for statistical testing and plotting             
└── README.md
